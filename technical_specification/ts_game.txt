 BA-GAME-2.2 (полный, заменяет 2.0 и дельту 2.1)

**Совместим с:** `BA-PLAT-4.2`, `BA-SDK-1.1`, протокол 1.
**Назначение:** самодостаточное задание для разработчика (в том числе ИИ) браузерной игры-«картриджа». Нумерация сквозная §1–§17; ссылки на прежние §3.x не применяются.

## §1. Что вернуть

Ты — разработчик браузерных игр. Ты создаёшь **готовый игровой картридж**: один ZIP-архив, который владелец портала загружает в CRM, и игра сразу работает. Владелец не программист: он не будет ничего дописывать, собирать, компилировать или настраивать. Всё необходимое — внутри архива.

1. Файл `<id>-<version>.zip` со структурой из §3.
2. Текстом в ответе: `manifest.json`, отчёт самопроверки (§15), перечень отклонений (§16).
3. Если приложить ZIP технически невозможно — выведи **полное содержимое каждого файла** без сокращений и многоточий, плюс `pack.py` (Python 3, только стандартная библиотека), собирающий корректный ZIP.

Запрещены макет, заготовка, псевдокод, `// TODO`, «здесь добавьте логику», незаполненные ассеты, демонстрационный каркас. Игра играбельна от первого кадра до экрана результатов.

★ CRM автоматически создаёт карточку игры из твоих `manifest.json` и `catalog/*.json`. Всё, что ты не заполнишь, придётся вводить владельцу вручную — это дефект картриджа.

## §2. Технические основы

* Чистые HTML5 + CSS3 + JavaScript ES2022. **Классические скрипты** (`<script defer src=...>`), без ES-модулей, сборщиков, npm, TypeScript, транспиляции.
* Рендер: Canvas 2D (предпочтительно) либо WebGL2. Phaser разрешён, только если готовый минифицированный файл лежит внутри пакета и имеет совместимую лицензию.
* Никаких сетевых запросов, кроме загрузки собственных файлов пакета — **только относительными путями**.
* Игра работает внутри `<iframe>` на отдельном домене, по пути вида `/v/<hash>/`, в песочнице `sandbox="allow-scripts allow-same-origin"` (при `pointerLock` добавляется `allow-pointer-lock`), с CSP:
  `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; media-src 'self' blob:; font-src 'self' data:; connect-src 'self'; worker-src 'self' blob:; form-action 'none'; object-src 'none'; base-uri 'self'`.
  При `capabilities.wasm: true` платформа добавляет `'wasm-unsafe-eval'`.
* ★ Игра обязана работать и в резервном режиме **opaque origin** (sandbox без `allow-same-origin`): без `localStorage`, `sessionStorage`, `IndexedDB`, `document.cookie`. Всё сохранение — через `ba.storage`.
* ★ Тег `<base>` запрещён. Игра не знает и не должна знать домен портала, идентификаторы пользователя, cookies.

## §5. `manifest.json` — заполняется полностью

```json
{
  "cartridge": 1,
  "id": "neon_snake",
  "version": "1.0.0",
  "sdkVersion": "^1.0",
  "protocol": 1,
  "name": "Neon Snake",
  "entry": "index.html",
  "genre": "arcade",
  "tags": ["reflex", "skill", "endless"],
  "supportedLanguages": ["en", "de", "nl", "ru", "fr", "es"],
  "defaultLanguage": "en",
  "mobileSupport": true,
  "orientation": "any",
  "estimatedPlayMinutes": 6,
  "theme": { "accent": "#39FF88" },
  "score": {
    "type": "integer", "unit": "points", "direction": "higher_is_better",
    "minValue": 0, "maxValue": 100000, "schemaVersion": 1
  },
  "limits": { "minPlaytimeSeconds": 15, "maxSessionSeconds": 1800, "pauseOnBlur": true },
  "capabilities": { "wasm": false, "pointerLock": false, "storage": "sdk", "externalOrigins": [] },
  "leaderboard": { "enabled": true, "claimedVerification": "heuristic_validated" },
  "verification": {
    "profile": { "maxPointsPerSecond": 60, "maxIdleGapMs": 5000 },
    "eventKinds": ["start", "eat", "turn", "level", "collide", "end"],
    "eventSchema": { "type": "object", "additionalProperties": true }
  },
  "assets": {
    "cover": "assets/cover.webp",
    "screenshots": ["assets/screen-1.webp", "assets/screen-2.webp"],
    "critical": [
      "index.html", "css/style.css", "js/ba-sdk.js", "js/rng.js", "js/game.js",
      "locales/en.json", "assets/font-main.woff2", "assets/sprite.webp"
    ],
    "criticalPathBytes": 900000
  },
  "credits": [{ "author": "...", "license": "CC0-1.0", "aiGenerated": true }]
}
```

Правила полей:

* `id` — `^[a-z][a-z0-9_]{1,38}[a-z0-9]$`: 3–40 символов, начинается буквой, заканчивается буквой или цифрой, только `[a-z0-9_]`. Никогда не меняется. ★ Платформа строит из него адрес игрового домена заменой `_` на `-`, поэтому завершающее подчёркивание запрещено, а метки вроде `admin`, `api`, `www`, `staging` использовать нельзя. Публичный адрес страницы игры (слаг) платформа создаёт сама из названия — придумывать его не нужно.
* `version` — semver; при обновлении игры увеличивается, `id` остаётся прежним.
* `sdkVersion` — semver-range совместимости (`"^1.0"`), `protocol` — `1`.
* `genre` — ровно один из: `arcade, puzzle, action, racing, simulator, strategy, sports, casual, logic, platformer`. `puzzle` — сборка/сопоставление; `logic` — дедукция/планирование.
* `tags` — до 8, английские слова в нижнем регистре.
* `supportedLanguages` — заявленные языки; обязательны `defaultLanguage` и `en`. Стартовый набор портала: `en, de, nl, ru, fr, es`.
* `score.maxValue` обязателен, `null` запрещён. `score.unit` — `points|ms|items|errors`. `schemaVersion` увеличивается только при изменении смысла очков.
* `limits.minPlaytimeSeconds` ≥ 5 (минимальная партия, не порог голосования), `maxSessionSeconds` ≤ 7200.
* `capabilities.externalOrigins` — **всегда пустой массив**; `capabilities.storage` — **только `"sdk"`**.
* `leaderboard.claimedVerification` — `client_reported | heuristic_validated | replay_verified`. Не завышай: `replay_verified` допустим только если вся логика детерминирована от seed, и тогда `verification.eventSchema` и `eventKinds` обязательны. Уровень присваивает платформа, манифест — заявка.
* `assets.critical` — точный перечень файлов до первого игрового кадра, **обязательно включая** `index.html`, `css/style.css`, `js/ba-sdk.js`, `js/rng.js`, `js/game.js`, `locales/<defaultLanguage>.json`, шрифты и графику первого экрана. Суммарный gzip ≤2 МБ; платформа пересчитывает фактическое значение после подмены SDK. Остальное грузится лениво.
* `theme.accent` — акцентный цвет карточки в каталоге.
* `credits` — автор, лицензия, признак ИИ-происхождения по каждому материалу.

## §6. SDK — единственный способ связи с порталом

Файл `js/ba-sdk.js` подключается первым: `<script defer src="js/ba-sdk.js"></script>`.
★ Платформа **всегда** заменяет этот файл официальной реализацией при публикации; исходный ZIP сохраняется неизменным. Поэтому:

* если официальный файл приложен — вложи его байт в байт;
* иначе создай заглушку с шапкой `/* BA-SDK MOCK — the platform replaces this file at publish time */`, реализующую **ровно** интерфейс ниже. Заглушка автономна: режим `guest`, язык из `?lang=` или `en`, строки из `locales/`, при неудаче — встроенная копия `locales/en.json`; `submitResult` возвращает правдоподобный успешный ответ; `top()` — 10 фиксированных записей; хранилище — в памяти. Заглушка не использует запрещённые API.
* Игровой код не зависит от внутренностей заглушки — только от контракта.

```js
const ba = await BreaktimeArcade.init({ timeoutMs: 5000 });

ba.context = {
  sessionId, gameId, gameVersion,
  mode,            // "guest" | "user" | "autotest" | "preview"
  nickname,        // строка или null (гость)
  language,        // строка кода языка, список НЕ ограничен шестью
  fallbackLanguage,
  strings,         // объединённый словарь (портал может переопределить тексты)
  score,           // { type, unit, direction, minValue, maxValue }
  limits,          // { minPlaytimeSeconds, maxSessionSeconds, pauseOnBlur }
  trustLevel,
  seed             // строка; источник детерминизма
};

ba.ready();
ba.t(key, params);                                  // ICU/CLDR
ba.on('pause' | 'resume' | 'visibility' | 'session' | 'autotest:finish', cb);
await ba.submitResult({ value, durationMs, eventLog, seed, clientMeta });
// -> { status, rank, isPersonalBest, isRecord, trustLevel, code }
await ba.leaderboard.top(10);                       // -> { entries:[{rank,nickname,value}], myRank }
await ba.leaderboard.myBest();                      // -> { value, achievedAt } | null
await ba.storage.get(key);
await ba.storage.set(key, value);                   // суммарно ≤64 КБ
await ba.storage.remove(key);
const ctx = await ba.newSession();                  // ★ новый контекст: sessionId и seed
ba.exit();
ba.fail(code, message);
```

Правила использования:

1. Все обращения — с `try/catch` и таймаутами: инициализация 5 с, отправка 10 с, чтение 5 с. Отсутствие SDK не даёт «белый экран»: покажи экран ошибки с кнопкой «Повторить».
2. Не более 60 обращений к SDK в минуту. Не пиши в хранилище каждый кадр: дебаунс настроек ≥1 с. Ключи хранилища версионируй (`settings.v1`, `save.v1`) — данные переживают обновление игры.
3. ★ **Гость:** `submitResult` возвращает `{status:"guest", code:"E_GUEST_FORBIDDEN", rank:null, isRecord:false}`. Это **не ошибка**: результат показывается полностью, ретраи запрещены, рядом — строка «Результат не сохраняется» и приглашение зарегистрироваться.
4. ★ Ретраи (до 3, с экспоненциальной задержкой) — только при сетевых/временных отказах. Не ретраить: `guest`, отказ проверки, выход за границы, истечение сессии. Повторный вызов с тем же результатом безопасен: ключ идемпотентности один на сессию, свои ключи и заголовки не изобретай.
5. ★ `newSession()` возвращает новый контекст; используй **новый `seed`**, старый считать недействительным. При отказе (например, лимит) останься на экране результатов с нейтральным сообщением.
6. ★ Неизвестные события и поля контекста игнорируй молча — контракт расширяется обратно совместимо.
7. Секреты, e-mail, логин, идентификаторы пользователя игра не получает и не запрашивает.

## §7. Обязательные экраны и поток

1. **Стартовый экран**: название, крупная кнопка START, краткое правило в одну строку, переключатель звука, подсказки управления отдельно для ПК и сенсора.
2. **Игровой экран**: HUD со счётом и целью, кнопка паузы.
3. **Пауза**: затемнение, RESUME / RESTART / EXIT. При потере фокуса — автопауза, звук выключен, цикл не молотит вхолостую.
4. **GAME OVER** — яркий экран в стилистике аркадных автоматов 1990-х: крупная контрастная типографика, ретро-рамка, энергичная, но не мигающая анимация, звук фанфар. Показывает: GAME OVER, YOUR SCORE, BEST SCORE, место, TOP-10, PLAY AGAIN, EXIT. Надпись **NEW HIGH SCORE — только после `isRecord === true` от сервера**.
5. **Отправка результата**: состояние «сохраняем…», затем подтверждённый результат.
6. **Гость** (`mode === "guest"`, `nickname === null`): результат показывается полностью, ненавязчивая строка «Результат не сохраняется» и приглашение зарегистрироваться. Игра полностью играбельна и не ограничена.
7. **PLAY AGAIN** вызывает `ba.newSession()` и **полностью** сбрасывает состояние: таймеры, слушатели, объекты, звук, частицы, счёт, журнал событий; использует новый seed. После 20 перезапусков память не растёт.
8. **EXIT** вызывает `ba.exit()`.

Порядок для авторизованного игрока: завершение → `submitResult` → проверка → показ подтверждённого результата и места. До подтверждения рекорд не объявляется. `mode === "preview"` ведёт себя как гость.

## §8. Детерминизм, счёт и журнал событий

* ГПСЧ mulberry32 (или аналог) в `js/rng.js`, инициализируемый числовым хешем `ba.context.seed`. Вся влияющая на результат случайность — только из него.
* Один числовой результат в границах манифеста; счёт не может выйти за `maxValue`.
* Журнал событий передаётся в `submitResult`:

```json
{ "v": 1, "seed": "<seed>", "events": [
  { "t": 0, "k": "start", "d": {} },
  { "t": 1530, "k": "eat", "d": { "x": 7, "y": 3 } }
]}
```

`t` — целые миллисекунды от старта партии, не убывают, ≤ `durationMs + 1000`; `k` — только из `verification.eventKinds` (≤32 кодов); журнал ≤20 000 событий, ≤2 МиБ до сжатия и ≤256 КиБ gzip. Пиши значимые события, а не каждый кадр. `durationMs` — фактическая длительность партии без пауз.

## §9. Режим автотеста (обязателен)

При `ba.context.mode === "autotest"`:

* игра **сама** начинает партию без стартового экрана и без звука;
* использует `ba.context.seed`, играет детерминированно простейшей встроенной стратегией;
* завершает партию и вызывает `submitResult` с результатом в границах манифеста **не позднее 25 секунд** реального времени;
* немедленно завершает партию по событию `ba.on('autotest:finish', ...)`;
* не показывает модальных экранов, не ждёт ввода, не пишет ошибок в консоль;
* ★ не обязана выдерживать `minPlaytimeSeconds` — служебные сессии освобождены от минимума; верхняя граница 60 с.

## §10. Локализация

* Все без исключения строки — через `ba.t(key)`. Конкатенация и хардкод запрещены; пустые подписи и вывод технических ключей на экран запрещены.
* `locales/<lang>.json` для всех заявленных языков **и обязательно `en`**; одинаковый набор ключей; UTF-8; плюрализация через ICU (`{count, plural, one {# life} other {# lives}}`).
* ★ Список языков платформы расширяем: `context.language` может содержать код, которого нет в пакете. Порядок отката: `strings` (словарь портала) → `locales/<language>` → `locales/<fallbackLanguage>` → встроенная копия `en`. Игра не должна падать и не должна показывать ключ.
* Минимальный обязательный набор ключей (плюс собственные):
  `game_title, start, pause, resume, restart, game_over, your_score, best_score, new_record, play_again, exit, loading, error_sdk, error_network, result_saving, result_rejected, result_retry, session_expired, guest_notice, register_cta, controls_hint, orientation_hint, sound_on, sound_off, rank, top_scores`.
* Немецкий текст длиннее английского примерно на 35 % — интерфейс не должен ломаться. Шрифты — только из пакета, в формате `woff2`, с кириллицей и диакритикой.

## §12. Поведение при сбоях (обязательно реализовать)

| Ситуация | Поведение |
|---|---|
| Потеря сети во время партии | пауза, индикатор, состояние партии сохраняется в памяти |
| Восстановление сети | возобновление с того же места |
| Сбой при отправке результата | нейтральный статус, до 3 повторов, кнопка «Повторить отправку» |
| Отказ после повторов | понятное локализованное сообщение; результат не теряется до старта новой партии |
| Истечение сессии | сообщение «Сессия завершена», предложение сыграть снова, без повторов |
| Отказ проверки результата | нейтральный текст без обвинений и технических кодов, без повторов |
| Гость | результат показан полностью, уведомление о несохранении, без повторов |
| SDK не ответил за 5 с | экран ошибки с кнопкой «Повторить», не пустой экран |
| Потеря фокуса / сворачивание | автопауза, звук выключен, цикл не молотит вхолостую |

Потеря результата после длинной партии из-за кратковременного сбоя сети недопустима.

## §13. Качество, бюджеты, доступность

| Показатель | Порог |
|---|---|
| Критический путь (`assets.critical`, gzip, после подмены SDK) | ≤2 МБ |
| Полный пакет | ≤8 МБ желательно, ≤25 МБ предел |
| Старт до интерактива | ≤5 с, профиль Fast 4G (9 Мбит/с, 60 мс RTT) |
| FPS | ≥60 на ПК, ≥30 на эталонном Android |
| Память вкладки | ≤300 МБ, без роста после 20 перезапусков |
| Разрешения | 320×480 … 2560×1440, без выхода за iframe |
| Изменение размера | корректно, **без перезапуска партии** |
| Цикл рендера | один `requestAnimationFrame`, `devicePixelRatio` ≤2 |

* Управление осваивается за ≤30 секунд. Сенсорные цели ≥44×44 px, цели на ПК ≥24×24 px, текст ≥14 px, контраст ≥4,5:1. На игровой поверхности `touch-action: none`, учёт safe-area.
* Клавиши перехватываются только внутри игровой области и только после старта партии; страница портала должна прокручиваться, пока игра не начата. Canvas получает фокус по клику.
* Звук — только после жеста пользователя, с видимым переключателем; состояние сохраняется через `ba.storage`. Игра полностью работоспособна без звука; информация не передаётся только цветом или только звуком.
* **Мигание чаще 3 раз в секунду запрещено**, включая GAME OVER. `prefers-reduced-motion` уважается.
* Графика: собственный узнаваемый стиль, аккуратные ассеты, плавные анимации, частицы и обратная связь на каждое действие. Разрешение растровых ассетов не ниже отображаемого размера ×1 (×2 для Retina-критичных). Растяжение, размытие, временные заглушки, отладочные надписи и «серые квадратики» запрещены.
* Никаких бесконечных циклов, утечек памяти, дублирующихся слушателей и таймеров.
