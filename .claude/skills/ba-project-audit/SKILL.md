# BA Project Audit

Read-only skill. Не изменяй файлы проекта.

## Порядок

1. Прочитай `CLAUDE.md`, `README.md`, `docs/project-reference/README.md`,
   `docs/architecture.md`, `docs/api.md` и релевантные разделы ТЗ.
2. Проверь происхождение и SHA-256 нормативных файлов; не копируй полные
   ТЗ в отчёт без необходимости.
3. Сними baseline: `git status --short --branch`, `git log -10 --oneline`,
   `git diff --stat`, `git remote -v`.
4. Инвентаризируй `apps/`, `config/`, `tests/`, `Makefile`, compose,
   миграции и пустые/заглушечные файлы.
5. Запусти только доступные и безопасные проверки: `git diff --check`,
   `make test`, `make lint`, `make types`, `./verify_stack.sh`. Если проверка
   невозможна, зафиксируй команду, exit code и причину — не выдавай
   непроверенное за PASS.
6. Сопоставь факты с требованиями ТЗ. Для каждого вывода укажи файл,
   команду или раздел ТЗ.
7. Раздели факты, гипотезы и рекомендации. Не придумывай endpoint'ы,
   поля, версии и результаты.

## Критерий завершения

- Есть список проверенных требований и фактических доказательств.
- Есть blockers, risks и next steps.
- Ни один файл проекта не изменён.
- Все непроверенные области названы явно.
